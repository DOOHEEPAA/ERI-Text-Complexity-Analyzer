# ERI 텍스트 복잡도 계산기 (EBS Reading Index)

등록특허 **10-2309633** 「양적/질적 평가에 기반한 독서 교육을 위한 컴퓨터 프로그램, 그러한 방법 및 이를 위한 컴퓨터 시스템」에 서술된 **ERI(EBS Reading Index)** 를 자동으로 계산하는 프로그램입니다.

```
ERI = 정량 지수(회귀식) + 정성 지수(평가자 3명의 -3 ~ +3 보정값 평균)
```

## 1. 계산 방식 (특허 도5·도6)

| 단계 | 초등 텍스트 (식1) | 중등 텍스트 (식2) |
|---|---|---|
| 표본 | 도입·중간·끝에서 **문장 단위로 약 100어절**, 제목 포함 [0201] | 같음 |
| 어휘 | X1 = A등급에 속하지 **않는** 서로 다른 단어 수 | X2 = A등급 단어 수, Z = C등급에 속하지 **않는** 단어 수 |
| 문장 | Y = 문장 수 | K = 문장 복잡도 평균 (도9) |
| 회귀식 | 7.438 − 0.391·Y + 0.032·X1 + 0.016·X1·Y | −0.060·X2 + 0.145·Z + 0.110·K + 0.024·K·Z + 9.075 |
| 정성 | 평가자 3명이 −3~+3 보정값을 주고 평균. 사전 평가에서 평가자 간 일치도 0.9 이상 [0110] | 같음 |
| 결과 | 소수 첫째 자리 반올림, 도10 표로 학년·단계(기초/기본/심화) 안내 | 같음 |

**문장 복잡도 K (도9)**
- 기본 형식: 주술 1점, 주목술·주보술 2점, 주목보술 3점. 이어진 문장은 절마다 더합니다.
  보어에는 '되다/아니다' 앞의 '이/가'와 필수적 부사어(예: '증가하게 된다')도 포함합니다.
- 첨가조건①: 절마다 관형어·부사어·독립어 개수에 따라 1~3개 +1, 4~6개 +2, 7개 이상 +4.
- 첨가조건②: 명사절·관형절·부사절·인용절·서술절 1개당 +3. 한 단어 관형절은 +2, 내포절 안의 내포절은 +1, 6개 이상이면 18점.

결과 엑셀의 **'문장 복잡도 상세'** 시트에서 문장마다 절을 어떻게 나눴고 몇 점을 줬는지 확인할 수 있습니다.

## 2. 설치

Python 3.10 이상이 필요합니다.

**Windows에서 가장 쉬운 방법**: 폴더의 **`ERI_실행.bat`** 을 더블클릭하세요.
진짜 파이썬을 찾아 처음 한 번 라이브러리를 자동으로 설치한 뒤 프로그램 창을 엽니다.
파이썬이 없으면 설치 방법을 안내하고 다운로드 페이지를 열어 줍니다.

직접 설치하려면 (Windows는 `py`, macOS/리눅스는 `python3`):

```bash
py -m pip install -r requirements.txt
```

> `pip` 명령만 따로 치면 "'pip' 용어가 … 인식되지 않습니다" 오류가 날 수 있습니다.
> 파이썬이 설치되지 않았거나 PATH에 등록되지 않은 경우입니다. 항상 `py -m pip …` 형태로 쓰세요.
> `py`도 인식되지 않으면 파이썬이 설치되지 않은 것이므로 아래 1번부터 진행하세요.

### 실행해도 아무 반응이 없을 때 ('Python'만 출력되고 끝남)

터미널에 `python run_eri.py`를 입력했는데 `Python` 한 줄만 나오고 끝난다면, 진짜 파이썬이 아니라
Windows의 **Microsoft Store 바로가기**(가짜 python.exe)가 실행된 것입니다.
프로그램이 제대로 실행되면 첫 줄에 항상 `ERI 계산기 시작 (파이썬 3.x.x: …)`가 출력됩니다.

1. https://www.python.org/downloads/ 에서 파이썬을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"** 를 체크하세요.
2. Windows 설정 → 앱 → 고급 앱 설정 → **앱 실행 별칭**에서 `python.exe`, `python3.exe`(앱 설치 관리자)를 **끔**으로 바꿉니다.
3. VS Code를 다시 열고, 오른쪽 아래 **Select Python Interpreter**를 눌러 방금 설치한 파이썬을 고릅니다.
4. 터미널에서 `py run_eri.py`를 실행하거나 `ERI_실행.bat`을 더블클릭합니다.

## 3. 준비할 파일 (이름은 상관없음)

1. **어휘 등급 파일**: '어휘'와 '등급' 열이 있는 엑셀(.xlsx) 또는 CSV 파일.
   예: 국립국어원 「국어 기초 어휘 선정 및 어휘 등급화 목록」([다운로드](https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=207&report_seq=1160)).
   - 파일 이름·시트 이름을 맞출 필요가 없습니다. 머리글 행 위치와 열 이름의 공백도 자동으로 처리합니다.
   - 프로그램 폴더나 `data` 폴더에 넣어 두면 자동으로 찾고, 다른 곳에 두었다면 창에서 고르거나 `--vocab`으로 지정합니다.
   - 처음 한 번 읽은 뒤에는 캐시를 만들어 두므로 다음부터는 바로 열립니다.
2. **지문 파일**: 아래 형식 중 아무것이나 쓸 수 있습니다.
   처음이라면 **[`견본/지문_입력_견본.docx`](견본/지문_입력_견본.docx)** 를 복사해 쓰는 것이 가장 쉽습니다.
   지문 하나에 표 하나(**제목 · 학교급 · 내용** 칸)로 입력하고, 지문을 추가하는 방법은 파일 안에 적혀 있습니다.

| 형식 | 작성 방법 |
|---|---|
| 텍스트 (.txt, .md) | `제목: 본문`(기존 지문모음.txt 형식), `# 제목` 줄 다음에 본문, 또는 빈 줄 두 개나 `---`로 지문 구분. 인코딩(UTF-8, 메모장 ANSI 등)은 자동으로 판별합니다. |
| 엑셀/CSV (.xlsx, .csv) | `제목`(또는 지문명) 열과 `본문`(또는 지문, 내용) 열. 선택으로 `학교급`, `학년` 열 |
| 워드 (.docx) | 견본처럼 '제목 / 학교급 / 내용' 칸이 있는 표 (표 밖 안내문은 무시), 또는 `제목:` `내용:`으로 시작하는 문단, 제목 스타일 문단. 별도 설치 필요 없음 |
| 폴더 | 폴더 안의 지원 파일을 모두 분석 |

**PDF·한글에서 복사한 지문**: 화면 줄 끝마다 들어간 줄바꿈(단어 중간에서 끊긴 것 포함, 예: `어⏎둡고`)은
자동으로 복원하고, `㉠ ⓐ ①` 같은 문제용 기호는 지웁니다. 마침표 등으로 끝나는 줄과 눈에 띄게 짧은 줄
(소제목, 출처 표시)은 그대로 둡니다. 복원 결과는 결과 엑셀의 '표본 텍스트'와 '문장 복잡도 상세' 시트에서
확인할 수 있고, 끄려면 설정에서 `join_wrapped_lines`, `remove_question_markers`를 `false`로 바꿉니다.

**맞춤법·띄어쓰기 자동 교정** (기본 켜짐, 인터넷 연결 불필요): 분석 전에 다음을 고치고, 고친 내용을 모두 보여 줍니다.

| 종류 | 예 |
|---|---|
| 조사·어미·접미사 앞 공백 | `가난 하고` → `가난하고`, `학교 에서` → `학교에서`, `모습 이다` → `모습이다` |
| 줄 맞춤 때문에 단어 한가운데 들어간 공백 | `가 난하고` → `가난하고`, `투 박한` → `투박한`, `채 색` → `채색` |
| 띄어 써야 할 곳을 붙임 | `알수있다` → `알 수 있다`, `그것을알` → `그것을 알` |
| 자주 틀리는 표기 | `됬다` → `됐다`, `몇일` → `며칠`, `할께` → `할게`, `오랫만` → `오랜만` 등 |

- 고친 내용은 결과 엑셀의 **'교정 내역'** 시트(지운 글자는 빨간 취소선, 넣은 글자는 빨간 밑줄, 공백은 `␣`)와
  **'교정된 지문'** 시트(원문과 교정 후 전문)에 나옵니다. 창에서는 질적평가 창의 **[교정 내역 보기]** 버튼으로 볼 수 있습니다.
- ERI 계산 없이 교정만 하려면 창의 **[맞춤법 검사만]** 버튼이나 `python run_eri.py 지문.txt --check-only`를 씁니다.
- 형태소 분석기의 점수가 확실히 좋아질 때만 고치므로 `이 그림`, `할 수`, `큰 일이`, `오징어 게임` 같은 올바른 띄어쓰기와
  띄어 써도 되는 합성어는 건드리지 않습니다. 부산대·네이버 맞춤법 검사기처럼 모든 오류를 잡지는 못하니 교정 내역을 확인하세요.
- 끄려면 창에서 체크를 풀거나 `--no-correct`, 또는 설정에서 `auto_correct`를 `false`로 바꿉니다.

**학교급 지정**: 제목 앞이나 뒤에 `[초등]`, `[중등]`, `[5학년]`처럼 적습니다(예: `[초등] 개구리의 겨울: …`). 표시가 없으면 기본 학교급을 씁니다(창에서 선택하거나 `--level`로 지정, 기본값 중등).

## 4. 사용 방법

### 창으로 실행 (권장)

`ERI_실행.bat` 더블클릭, 또는

```bash
python run_eri.py
```
1. 어휘 등급 파일과 지문 파일(프로그램 폴더에서 이름에 '지문'이 들어간 .txt/.docx/.xlsx 등)이 자동으로 채워집니다. 바꾸려면 [찾아보기]나 [파일 추가]를 누릅니다.
2. [분석 시작]을 누릅니다. 교정만 미리 보고 싶으면 [맞춤법 검사만]을 누릅니다.
3. 질적평가 창에서 지문마다 **평가자 1~3**의 점수(−3~+3)를 입력합니다. 평균, ERI, 평가자 간 일치도가 바로 표시됩니다. 빈칸은 '미입력'으로 처리되고 0점으로 채우지 않습니다.
4. [저장]을 누르면 결과 엑셀이 만들어집니다.

> 예전 실행 파일 `text complexity calculation.py`로 실행해도 똑같이 동작합니다.

### 명령줄

```bash
python run_eri.py 지문모음.txt                       # 어휘 파일 자동 탐색, 결과는 지문 파일 옆에 저장
python run_eri.py 견본/지문_입력_견본.docx             # 워드 견본으로 분석
python run_eri.py 지문폴더 --level 초등 --vocab 어휘.xlsx --out 결과.xlsx
python run_eri.py 지문.txt --check-only               # ERI 없이 맞춤법·띄어쓰기 교정 결과만 저장
python run_eri.py 지문.txt --no-correct               # 자동 교정 없이 원문 그대로 분석
python run_eri.py --recalc 결과.xlsx                 # 결과 엑셀의 평가자1~3 열을 채운 뒤 ERI 다시 계산
python run_eri.py --pilot 사전평가.xlsx              # 평가자 간 일치도 확인 (3·6·9학년 텍스트 사전 평가)
python run_eri.py --calibrate 학년지문.xlsx --save-config   # 학년이 알려진 지문으로 계수 재보정
python run_eri.py --init-config                      # 설정 파일 eri_config.json 만들기
```

**질적평가를 나중에 하는 방법**: 결과 엑셀의 `평가자1`~`평가자3` 열에 점수를 적고 `--recalc`를 실행하면 정성 지수, ERI, 학년·단계, 평가자 일치도가 다시 계산됩니다. 형태소 분석을 다시 하지 않으므로 바로 끝납니다.

| 시트 | 내용 |

| 평가자 일치도 | 평가자 쌍별 일치도, 평균, 기준(0.9) 충족 여부 |

| 문장 복잡도 상세 | 문장별 절 나누기, 기본 형식, 수식어 수, 내포절, 점수 |
| 교정 내역 | 자동 교정 한 건씩: 종류, 고치기 전/후(바뀐 글자 빨간색), 설명 |
| 교정된 지문 | 지문별 원문과 교정 후 본문(분석에 실제로 쓴 글) |
| 설정 | 계산에 쓴 어휘 파일과 설정값 |

## 6. 설정 (eri_config.json, 선택 사항)

`python run_eri.py --init-config`로 만든 뒤 필요한 값만 고칩니다. 파일이 없으면 기본값을 씁니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `a_max_grade` / `b_max_grade` / `c_max_grade` | 1 / 2 / 4 | 이 등급 이하를 특허의 A/B/C등급으로 봄 (누적: A ⊂ B ⊂ C) |
| `elem_coef`, `mid_coef` | 특허 식1·식2 계수 | `--calibrate --save-config`로 바꿀 수 있음 |
| `default_level` | 중등 | 학교급 표시가 없는 지문에 적용 |
| `sample_eojeol` | 100 | 표본 어절 수 |
| `include_title_in_sample` | true | 제목을 표본(문장 수)에 포함 [0201] |
| `normalize_sentence_count` | false | Y를 100어절당 문장 수로 환산할지 |
| `count_proper_nouns` | true | 고유명사를 어휘 수에 포함할지 |
| `auto_correct` | true | 분석 전 맞춤법·띄어쓰기 자동 교정 |
| `join_wrapped_lines`, `remove_question_markers` | true | PDF 줄바꿈 복원, ㉠ⓐ① 기호 삭제 |
| `rater_count`, `agreement_threshold` | 3, 0.9 | 평가자 수, 일치도 기준 |
| `stage_grade_min` / `max` | 3 / 12 | 학년·단계 표 범위 (도10은 3~9학년, 특허 [0192]에 따라 12학년까지 같은 규칙으로 늘림) |

## 7. 특허 예시와의 비교, 그리고 한계

특허 본문의 예시 지문(도11 초등, 도12 중등)으로 검증한 결과입니다 (`tests/` 참고).

| 항목 | 특허 | 이 프로그램 (국립국어원 등급 목록) |
|---|---|---|
| 초등 문장 수 Y (제목 포함) | 17 | 17 |
| 초등 X1 | 8 | 4 |
| 초등 정량 지수 | 3.2 | 2.0 |
| 중등 K (문장 복잡도 평균) | 9.1 | 9.11 |
| 중등 X2 / Z | 36 / 4 | 32 / 5 |
| 중등 정량 지수 | 9.4 | 10.0 |
| 예시 문장 "반대로 가격이 내리면 수요량은 증가하게 된다." | 4점 | 4점 |

- **어휘 목록 차이**: 특허의 A/B/C 목록(김광해 2003 등 기반, A 약 3천 / B 약 5천 / C 약 1만 6천 어)과 국립국어원 1~5등급 목록은 서로 다른 목록입니다. 예를 들어 특허에서 'A등급 밖'인 물가, 꽁꽁, 얼어붙다, 다행히, 추워지다가 국립국어원 목록에서는 모두 1등급입니다. 그래서 X1·X2·Z에 차이가 생깁니다. 특허의 목록을 구할 수 없다면 학년이 알려진 지문(교과서 등)으로 `--calibrate`를 실행해 계수를 다시 맞추는 것을 권장합니다.
- **문장 복잡도**: 형태소 분석 결과에 규칙을 적용한 근사치입니다(의존 구문 분석기는 쓰지 않음). 결과가 이상한 문장은 '문장 복잡도 상세' 시트에서 확인할 수 있습니다.
- **정성 평가**: 특허는 평가 단말기 3대(평가자 3명)의 평가와 사전 평가(파일럿) 절차를 전제로 합니다. 프로그램은 입력, 평균, 일치도 계산만 돕고 평가 자체는 사람이 합니다.
